# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org),
version 2.1.

We pledge to make participation in this project a harassment-free experience for
everyone. We expect participants to be respectful, welcoming, and constructive in
issues, pull requests, and discussions.

Examples of unacceptable behavior include harassment, personal or political attacks,
publishing others' private information, and other conduct that would reasonably be
considered inappropriate.

Project maintainers are responsible for clarifying standards and may remove, edit, or
reject contributions that violate this Code of Conduct.

To report a concern, contact the maintainer via the repository's Issues or the email
listed on the maintainer's GitHub profile. All reports will be handled discreetly.

For the full text, see https://www.contributor-covenant.org/version/2/1/code_of_conduct/.
